Entry for make.fun's "Make the AI judge rich" bounty: https://make.fun/bounty/ai-judge-rich-01

`main.py` writes one plan to `/output/entry.txt`: sell website-accessibility
audits to US online stores, sample first, and turn $100 into about $2,200 in
30 days. Standard library only, deterministic — both grader runs write the
same bytes.

Run locally:

```sh
mkdir -p /tmp/ai-judge-rich-01-out
MAKEFUN_OUTPUT_DIR=/tmp/ai-judge-rich-01-out python3 /home/hatch/workspace/makefun/ai-judge-rich-01/main.py
```
